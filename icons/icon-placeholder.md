# Icons Needed

This directory should contain the following PNG files:

- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

For now, the extension will work without these files, but Chrome may show a default icon.

You can create simple icons using any image editor with:
- A magnifying glass icon
- Blue/white color scheme to match Google's branding
- Transparent background

Or use any free icon generator tools online.
